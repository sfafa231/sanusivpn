Fitur

⚡Auto-reconnect cepatBegitu jaringan hilang atau berpindah (WiFi ⇆ seluler), tunnel langsung disambung ulang otomatis.
🛡️Mode TUN penuhSemua aplikasi ikut terlindungi — bukan sekadar proxy browser.
🔗Impor dari tautanTempel atau bagikan tautan vless:// vmess:// trojan:// ss:// langsung ke aplikasi.
📊Statistik langsungPantau kecepatan unggah/unduh dan riwayat koneksi.
🌙Desain gelap modernTampilan bersih, animasi halus, dan ikon Pengaturan Cepat (QS Tile).
🔋Sesi ringanBerjalan sebagai layanan latar dengan notifikasi resmi Android.

Cara pasang

  1. Unduh APK di atas (buka dengan Chrome).
  2. Jika diminta, aktifkan “Izinkan dari sumber ini” / Unknown sources.
  3. Buka Sanusi VPN → tab Server → + Tambah.
  4. Tempel tautan server (vless/vmess/trojan/ss) lalu Simpan.
  5. Kembali ke Utama, ketuk tombol besar untuk menyambung. Saat muncul dialog “Permintaan koneksi”, pilih OK.
Aplikasi ini adalah klien VPN/proxy. Ia tidak menyediakan server sendiri — Anda memakai akun/server milik Anda. Gunakan secara bertanggung jawab dan sesuai hukum yang berlaku.
